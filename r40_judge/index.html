    TECHNICAL IMPLEMENTATION

    A bounded agent, not an open shell.

    The model sees only HTTP, logs, metrics, current configuration, allowlisted actions, and failure feedback. A strict JSON parser and Safety Gate reject malformed or unapproved decisions. The executor changes only temporary local configuration and verifies the route over HTTP.

    01Model proposes the repair; code never supplies the hidden answer.
    02Failed actions become evidence for the next model decision.
    03Invalid output stops the case and restores its starting state.
    04Provider IDs, token usage, trace hashes, and all case outcomes are retained.
