# Demo video credits and scope

The R15 demo video is an original screen recording of the local EdgeSRE Guardian replay in Microsoft Edge. The script, captions, and visual interface were created for this project. It contains no music, stock footage, or third-party logos. Product names identify the actual NVIDIA model and Nebius service used in R13.

English narration was synthesized locally with the [Rhasspy Piper `en_US-ljspeech-medium` voice](https://huggingface.co/rhasspy/piper-voices/blob/main/en/en_US/ljspeech/medium/MODEL_CARD). The Piper voices repository is marked MIT, and this voice's model card identifies the [LJ Speech dataset](https://keithito.com/LJ-Speech-Dataset/) as public domain. The voice model itself is not distributed in this repository.

The video depicts **R13 Real Trace Replay**. It is not footage of a new Token Factory call. The two provider responses, actions, usage, and HTTP results are historical R13 evidence. The public UI generates zero API requests.
