# R41 judge testing guide

1. Open the [independent public judge page](https://edgesre-guardian-r40-judge.vercel.app/judge.html). Select D01 (repairable database wait, saved `/checkout` 503→200), D02 (beyond allowlist, 503→503 with abstention and rollback), then D03 (partial step fails before 503→200 recovery). Inspect the before/after HTTP cards, action timeline, raw observations, and downloadable hash-checked receipt. The label is **OFFLINE SIMULATION**: the hosted page does not run a fresh service or model request.
2. Open the [recorded incident page](https://edgesre-guardian-r40-judge.vercel.app/). Select a historical R37 recovery and an R38 failure. Inspect the provider response/request IDs, token usage, action, Safety Gate, HTTP status, and whether the system rolled back. The label is **REAL PROVIDER TRACE — RECORDED REPLAY**: saved Nebius decisions, zero new requests.
3. For fresh local HTTP operation, run `cd r40_judge` then `python judge_server.py --port 8765`. Open `http://127.0.0.1:8765/judge.html` and select each public scenario. The local server starts an isolated loopback service and uses the disclosed deterministic offline policy. Run `python -m unittest -v test_judge.py` in the same directory.
4. For the original R15 historical trace, run `python serve.py` from the repository root and open `http://127.0.0.1:8765/`. Run `python -m unittest discover -s engine -p "test_*.py" -v` to check the engine package.
5. For **real Runtime** inspection, read `engine/r9_live_probe_once.py` and `engine/r14_live_runtime.py`; run `python engine/r14_live_runtime.py` with no arguments to confirm the zero-request preflight. The adapter uses Nebius Token Factory's `/v1/chat/completions` endpoint and NVIDIA Nemotron 3 Nano. An operator with a distinct Owner authorization, current account/billing verification, fresh signed-in trial readbacks and a private server-side key can run `python engine/r14_live_runtime.py --execute`. These conditions are not supplied to general visitors, who can use the public test build free of charge. The public site has no Live inference route. Do not infer a current Live call from a replay or offline result.

The public site has no API key and no unrestricted inference endpoint. R38 abstention is 4/8; R39 blind test is NOT_RUN. The trial expires before the December 1–15 judging period; the hosted replay and saved offline receipts do not depend on that trial. Future uptime must be checked during the judging period.
